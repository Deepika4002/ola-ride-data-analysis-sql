# 📊 Ola Ride Data Analysis (SQL Project)

## 📌 Objective  
Analyze ride booking data to identify trends in rides, cancellations, and customer behavior  

## 🛠 Tools Used  
- SQL  
- Excel  

## 💾 SQL Work  
- Used GROUP BY for trend analysis  
- Used COUNT(), AVG() for aggregation  
- Filtered data using WHERE conditions  

## 📈 Key Insights  
- Peak booking time observed in evening  
- High cancellations by customers  
- Top customers contribute majority of rides  

## 💡 Business Recommendation  
- Increase drivers during peak hours  
- Improve service in high-cancellation areas  

## ▶️ How to Run  
1. Open MySQL Workbench  
2. Create database: CREATE DATABASE ola;  
3. Use database: USE ola;  
4. Run the SQL script
