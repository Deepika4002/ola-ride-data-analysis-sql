# 🚖 Ola Ride Data Analysis Project

Interactive Data Analytics project using **Power BI, SQL, and Excel** to analyze Ola ride booking trends, customer behavior, cancellations, revenue patterns, and vehicle performance.

---

# 📌 Project Overview

This project focuses on analyzing Ola ride booking data to uncover meaningful business insights and operational trends.

The analysis includes:
- Ride booking trends
- Revenue analysis
- Customer behavior
- Driver performance
- Ride cancellation analysis
- Vehicle performance insights

The project uses SQL for data analysis and Power BI for interactive dashboard visualization.
